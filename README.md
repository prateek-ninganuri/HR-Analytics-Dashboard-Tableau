## 📌 Project Overview

An interactive **HR Analytics Dashboard** built using **Tableau** to analyze employee attrition, workforce demographics, job satisfaction, and department-wise trends. The dashboard provides HR professionals with valuable insights to identify key factors influencing employee turnover and support data-driven workforce decisions.

---

## 🚀 Dashboard Features

- 📈 HR KPI Overview
  - Employee Count
  - Active Employees
  - Attrition Count
  - Attrition Rate
  - Average Employee Age

- 🏢 Department-wise Attrition Analysis

- 👥 Employee Distribution by Age Group

- ⭐ Job Satisfaction Heatmap by Job Role

- 🎓 Education Field-wise Attrition Analysis

- 🚻 Gender-wise Attrition Analysis

- 🎛 Interactive Education Filter

---

## 📊 Key Insights

- **Total Employees:** 1,470
- **Active Employees:** 1,233
- **Attrition Count:** 237
- **Overall Attrition Rate:** 16.12%
- **Average Employee Age:** 37 Years
- Research & Development recorded the highest employee attrition.
- The majority of employees fall within the **25–35 years** age group.
- Employees from the **Life Sciences** education field showed the highest attrition.
